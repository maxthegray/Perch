# Magpie: clipboard history (Maccy-style) — design

## Goal

Friends who have Perch but not Maccy get Maccy's core loop inside Perch: press a hotkey,
pick a recent clip from a popup, and it is back on the pasteboard. First built in Labs;
shipped in 1.9.0 as a stock feature with its own Settings tab, on by default. Bridging clips with the shelf is
later item #114 and out of scope here.

## Decisions

- **Tier:** stock Perch, its own "Magpie" Settings tab, on by default. Off means nothing
  runs: no pasteboard polling, no history database opened, no hotkey registered.
- **Labs unlock:** triple-clicking "Made by Max" only reveals the Labs tab and selects it. It no
  longer enables Smart Perch — every Labs feature starts off. The tab is renamed from
  "Smart Perch" to "Labs". While Smart Perch is on, the app calls itself "Perch Labs".
  "Remove Smart Perch and Delete Data" no longer hides Labs.
- **Selecting a clip copies it** (click, ⌘1–⌘9, or ↩ on the highlighted row). No
  auto-paste, so no Accessibility permission.
- **Captures what Maccy captures:** plain/rich text, images, and copied files (as file
  references). Every pasteboard representation is stored so a clip restores exactly.
- **Never records** clips marked `org.nspasteboard.ConcealedType`, `TransientType`,
  `AutoGeneratedType`, or the password-manager / snippet types Maccy ignores.
- **See Collected Data:** Smart Perch and Magpie each have a button opening a read-only window that
  lists every table in its database with its rows as stored (newest 500 per table, blobs
  shown as sizes). It never creates a database.
- **Name:** Magpie in Settings; the popup itself only says "Perch".
- **Looks:** Classic (default) is Maccy-like — a compact menu of just the clips that
  shrinks to fit as you search. Detailed is a card with source app, age and key hints.
- **Hotkey:** ⌥⌘C by default, rebindable. (It shadows Finder's Copy as Pathname.)
- **History:** newest first, 200 clips, re-copying an existing clip moves it to the top.
  Survives restarts. "Clear History" deletes it. Selected clip can be deleted with ⌥⌫.

## Architecture

- `Sources/ClipboardCore` (new target, GRDB, no AppKit):
  - `ClipCapture` — pure policy turning raw pasteboard items into a capture (kind, title,
    search text, file paths, content hash) or rejecting it.
  - `ClipStore` — SQLite store: insert-or-bump by content hash, 200-clip retention,
    summaries without blobs, representations on demand, delete, delete all.
  - `ClipSearch` — fuzzy filter: substring matches rank above subsequence matches; ties
    keep recency order.
- `Sources/Perch/Clipboard` (AppKit):
  - `ClipboardCoordinator` — `ObservableObject` behind the Labs switch; owns an optional
    `ClipboardFeature`, so off constructs nothing.
  - `ClipboardFeature` — owns the store, watcher, hotkey and panel.
  - `PasteboardWatcher` — polls `NSPasteboard.general.changeCount` every 0.5s.
  - `GlobalHotKey` — Carbon `RegisterEventHotKey` (no permission prompt).
  - `ClipboardPanel` — non-activating `NSPanel` at the cursor, clamped to the screen, with
    a SwiftUI search field and list.
  - `HotKeyRecorder` — small in-house shortcut recorder for the Labs pane.

## Testing

- `ClipboardCoreTests`: capture policy, store dedupe/retention/delete/reopen, search.
- `PerchTests`: Labs unlock no longer enables Smart Perch, removal keeps Labs visible,
  clipboard off creates no database, panel placement clamping, key combo rules.
- Manual: drive the real panel with window-scoped captures.
